The public collaboration page is [Sudden cardiac death](https://eccentric-health.github.io/scd-replication/).

Edit `index.html` and `styles.css`. The HTML file owns the published protocol. The page retains the protocol and design from the personal site. Its access form is the reviewed agreement version 1.4. The linked US and Sweden protocol drafts keep their existing Google Drive permissions.

Only public materials belong here. Completed forms, email assent, identities, approvals, and access reports belong in the private `eccentric-health/scd-access` repository. Model files belong in the private `eccentric-health/scd-models` repository. This site collects no submissions.

GitHub Pages publishes the repository root from the `main` branch. The former personal page redirects here.

Run `python3 scripts/check_site.py` before publication. The check uses Python's standard library and checks the public file list and local links.
